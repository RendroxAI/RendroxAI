FAQ

Frequently Asked Questions

Find quick answers concerning implementation times, legacy integrations, and data handling protocols.

How long does onboarding a new invoice layout or store configuration take?

Since our extraction framework separates data mappings from core scripts, onboarding a new vendor document layout or database store settings takes under 5 working days, requiring no redevelopment or downtime for the main bot registry.

How does Rendrox AI handle anomalies or unmatched transaction items?

Every document line is processed in isolated validation blocks. Any item that does not clear defined matching rules is quarantined in an exception folder. The system generates an immediate warning report to your operations team, preventing mis-postings or silent errors.

Is this compatible with legacy on-premise databases and ERP systems?

Yes. We utilize a combination of secure API connections (CPI interfaces) and desktop RPA orchestrators. This hybrid model allows us to bridge modern cloud tools with old on-premise mainframes, terminal clients, or windows desktop programs.

Where is customer data stored during file parsing operations?

Data privacy is vital. All transaction information is read, parsed, and posted in-memory locally. No customer transaction values or files are stored in our databases, maintaining full compliance with corporate security audits.
